# Mirror —— 一个"越聊越像你"的数字分身

> 复用一个通用记忆引擎，把它变成一个"会聊天、边聊边记住我、能被考出像不像我"的 Agent。
> 真正难的不是"记住一个人说过什么"，是"压制住底层大模型自己的人格和知识"。

## 一句话

我想做一个能复刻我的数字分身。做完发现：**记忆只是外壳，难的是让一个比我博学得多的大模型，学会"装成一个有边界的人"。**

## 它是什么

```
你（张旭鸿） ←—聊天—→ Mirror
                        ├─ 轮前：召回关于你的记忆 + 画像，注入提示词
                        ├─ 轮中：DeepSeek 用"第一人称"回答
                        └─ 轮末：从这轮对话抽事实，写入记忆库（自动去重/冲突消解）
                                   ↓
                    memory-hub（复用的记忆引擎：三层记忆 + 三路召回）
```

- **会聊天**：memory-hub 只提供 write/recall，不会对话；这里接 DeepSeek 让它开口。
- **有对象**：memory-hub 的记忆是给任意 subject 的，这里固定成"你"。
- **边聊边记**：每轮结束自动抽取"关于你"的事实入库。
- **能被考**：盲测 + 露馅测试，用数据回答"它到底像不像你"。

## 核心发现（面试能讲的东西）

### 发现一：镜像会"替人变强"

喂它「我选 Agent 是因为学历够、Java 饱和」，它答「因为 Agent 更有意思、边界模糊」。

**记忆引擎只存下了"我选了 Agent"这个结论，丢掉了"我为什么选"的理由。**
镜像把人的"现实但不够正确"的动机，洗成了"标准正确"的动机。

### 发现二：镜像会"替人懂知识"（人格泄漏）

问它「你懂 embedding 和 RRF 怎么结合吗」——一个从没喂过它的话题——它长篇科普、还主动要帮你整理面试话术。

**它不觉得这是在编造，因为那是底层大模型（DeepSeek）的参数知识，不是"关于张旭鸿这个人"的信息。**
镜像 = 大模型的脑子（全部能力）+ 你的记忆（薄薄一层皮）。

### 发现三：约束只能"盖"，不能"挖"

加了 system prompt 边界（"技术视野 = 你喂过的"）之后，再问 RRF，它老实答「这个我还没聊过」。

但换种问法（"帮我写个快排"），它照样能写。**模型的人格和知识刻在参数里，prompt 只能盖住，删不干净。**

**结论：复刻一个人的难点，不在"记住他说过什么"，在"压制模型自己"。**

## 踩过的坑（详见 DESIGN-MIRROR.md）

| # | 坑 | 根因 |
|---|---|---|
| M1 | 问"哪个学校"召回不到 | 没接向量，三路召回全空退化 |
| M2 | 历史记忆成"孤儿向量" | 写入时 vec_stale 硬编码 0，永不补嵌 |
| M3 | 自我介绍被漏存 | 抽取器"宁可漏"太激进，无兜底 |
| M4 | 评测误判"编造" | 判据用整串匹配，措辞一变就漏 |

## 怎么跑

```bash
# 1. 喂：双击「和镜像聊天.bat」，聊天 = 喂料，边聊边学
#    （每轮结束会打印 [记住] xxx = 它吸收成什么）
# 2. 考：双击「跑盲测.bat」，6 道题看它像不像你
#    （对比喂之前的基线：硬指标 4%、盲判 3.0/5）
```

聊天中：`/记忆` 看它记住了什么，`/画像` 看它眼中的你，`q` 退出。

## 技术栈

- 记忆引擎：memory-hub（复用，零第三方依赖，三层记忆 + 冲突消解 + 三路 RRF 召回）
- LLM：DeepSeek（对话 + 抽取 + 冲突消解）
- Embedding：DashScope text-embedding-v3（替换原 fastembed，解决 M1/M2）
- 评测：露馅测试（测"不编造"）+ 盲测（测"像不像"，硬指标关键词 + 软指标 LLM 盲判）

## 文件结构

```
mirror.py        镜像本体：聊天 + 短期记忆 + 边聊边记 + 人格约束
config.py        参数集中（模型/召回数/短期记忆轮数/数据库路径）
feed.py          批量喂料脚本（可选）
evaluate.py      露馅测试（它会不会编造）
blind_test.py    盲测（它像不像你）
blind_questions.py  盲测题目 + 你的真身答案
memory_hub/      复用的记忆引擎（17 文件）
DESIGN-MIRROR.md 工程设计与踩坑记录（M1-M4）
```
